# Canonical deployments

No CheapCoin Robinhood Chain contracts are deployed yet.

Before live mode is enabled, this directory will contain a machine-readable
manifest for each deployment with chain ID, address, bytecode hash, constructor
arguments, compiler settings, source-verification link, transaction hash, owner
Safe, operator, immutable reward token, and signed release tag.

An address absent from the latest signed manifest is not a supported CheapCoin
contract. Deployment records are append-only; superseded contracts remain listed
with an explicit status and reason.
